# @better-compute/provider-digitalocean

A DigitalOcean provider for better-compute: Droplets as VPS instances and offers, over plain `fetch` against the DigitalOcean API v2. It has no npm dependencies beyond `@better-compute/core` and `@better-compute/vps`.

It is not part of the `better-compute` umbrella: install it next to `better-compute`.

```sh
npm install @better-compute/provider-digitalocean
```

This package is under construction; the full documentation (configuration, token scopes, offers, networks) lands with the provider itself.
