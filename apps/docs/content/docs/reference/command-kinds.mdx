Commands reach a node over its gateway session, one lane per kind. _Retry-safe_ kinds are re-run after a crash between accept and completion; _self-terminating_ ones end the agent (a reboot, a kexec, an upgrade) and complete when it rejoins; _attested_ results are node-signed and verified before any transition; _destructive_ ones must be signed.
