Every method is `POST /api/compute/{group}/{method}` with a JSON object body, `content-type: application/json` and `X-Better-Compute: 1` (else `CSRF_REJECTED`), at most 64 KiB. Answers are `{ "data": … }` or `{ "error": { "code", "message", "details"? } }`; see [errors](/docs/reference/errors). Plugins are served under `/api/compute/plugins/{id}/{group}/{method}`.

A call is authenticated (except public methods), refused before any database access when the caller is outside the input tenant and the root tenant, and decided once on `action @ resource`. _+ items_ marks list methods, which also filter items one by one.
