Join tokens are single-purpose credentials that let a limited number of daemons join one pool for a limited time. The bearer form `bcjt_<id>.<secret>` is returned once, when the token is created; the control plane stores only the SHA-256 of the secret. Every method is decided on `compute-pool/{poolId}`. See [Joining nodes](/docs/guides/nodes/joining).

All 3 methods are served by this release.

| Method              | Kind     | Authorization                                 | Phase | Status     |
| ------------------- | -------- | --------------------------------------------- | ----- | ---------- |
| [`create`](#create) | mutation | `compute:join-tokens:create` @ `compute-pool` | v0.1  | registered |
| [`list`](#list)     | read     | `compute:join-tokens:read` @ `compute-pool`   | v0.1  | registered |
| [`revoke`](#revoke) | mutation | `compute:join-tokens:revoke` @ `compute-pool` | v0.1  | registered |

## create

`POST /api/compute/joinTokens/create`

Mints a role-`node` join token for one pool and returns its record with the bearer `token`, which is never shown again.

Only the pool's owner tenant can mint tokens for it; another tenant gets `NOT_FOUND`. A pool whose machines run no daemon (its `agent` is not `bcd`) answers `INVALID_STATE`. `expect` pins the token to one machine and must name at least one identifier, otherwise the call is `INVALID_INPUT`. `ttlSeconds` runs from 60 to 86,400 and `maxUses` defaults to 1.

The token id derives from the tenant, the calling identity and `idempotencyKey`. A retry with the same key returns the stored record without `token` and without a new IAM decision. The same key with a different pool, `expect` or `allowReclaim` is `CONFLICT`.

Publishes `security.join-token.created`, whose `pinned` field says whether the token has an `expect` binding.

- **Kind:** mutation
- **Authorization:** `compute:join-tokens:create` @ `compute-pool`
- **Module:** `server`
- **Phase:** v0.1 (registered)

## list

`POST /api/compute/joinTokens/list`

Lists a pool's join tokens in id order, never with their secrets.

By default only live tokens appear: not revoked, with uses left and not expired. `includeInactive: true` adds used-up, expired and revoked tokens. Pages hold up to 200 tokens (100 by default); pass the returned `cursor` to read the next page.

- **Kind:** read
- **Authorization:** `compute:join-tokens:read` @ `compute-pool`
- **Module:** `server`
- **Phase:** v0.1 (registered)

**Input**

| Field             | Type    | Required | Constraints                                                           |
| ----------------- | ------- | -------- | --------------------------------------------------------------------- |
| `tenantId`        | string  | yes      | at most 128 characters; matches `^[A-Za-z0-9._:-]{1,128}$`            |
| `poolId`          | string  | yes      | at most 128 characters; matches `^[A-Za-z0-9][A-Za-z0-9._:-]{0,127}$` |
| `includeInactive` | boolean |          | default `false`                                                       |
| `limit`           | integer |          | 1-200; default `100`                                                  |
| `cursor`          | string  |          | at most 64 characters; matches `^jt_[0-9a-hjkmnp-tv-z]{26,52}$`       |

## revoke

`POST /api/compute/joinTokens/revoke`

Revokes a join token at once and returns its record with `revokedAt` set.

Revoking a token that is already revoked returns it unchanged and publishes nothing. A token that does not exist in the tenant and pool is `NOT_FOUND`. A first revocation publishes `security.join-token.revoked`.

- **Kind:** mutation
- **Authorization:** `compute:join-tokens:revoke` @ `compute-pool`
- **Module:** `server`
- **Phase:** v0.1 (registered)

**Input**

| Field      | Type   | Required | Constraints                                                           |
| ---------- | ------ | -------- | --------------------------------------------------------------------- |
| `tenantId` | string | yes      | at most 128 characters; matches `^[A-Za-z0-9._:-]{1,128}$`            |
| `poolId`   | string | yes      | at most 128 characters; matches `^[A-Za-z0-9][A-Za-z0-9._:-]{0,127}$` |
| `tokenId`  | string | yes      | at most 64 characters; matches `^jt_[0-9a-hjkmnp-tv-z]{26,52}$`       |
